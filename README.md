# Car Manager PWA

Application personnelle locale de suivi automobile. Données conservées dans `localStorage` sur l'appareil.

## Fonctions
- véhicule et kilométrage ;
- calendrier mensuel ;
- vidange, filtres, pneus, freins, distribution, fluides, batterie, contrôle technique, assurance et révision ;
- échéances par date et/ou kilométrage ;
- statuts à jour, bientôt (30 jours ou 1 000 km), en retard ;
- dépenses annuelles ;
- sauvegarde/import JSON ;
- installation PWA et mode hors ligne.

## Publication GitHub Pages
Placez tous les fichiers à la racine du dépôt, activez Pages sur `main / (root)`, puis ouvrez l'URL HTTPS.

## Important
Les intervalles préremplis sont des exemples génériques. Respectez en priorité le carnet d'entretien du constructeur, la motorisation, l'âge et l'usage du véhicule. L'application ne remplace pas un diagnostic professionnel.
